# 搭哪班 · Which Ride

香港出门路线：现在出门搭哪一班最快到。列出全部合理方案、车费、平均和最坏用时，读取九巴、城巴、专线小巴的实时到站。

- 网址：https://trumancc.github.io/hk-transit-web/
- 纯静态页面，路线在浏览器里计算。
- 「记录这趟行程」把实际候车、上车、开车、到达时间提交到收集表单，用来改进估算。提交内容不含起点、终点或任何身份信息。

数据来源：运输署开放数据（经 hkbus 开源项目整理）、九巴、城巴、运输署小巴实时到站接口、港铁开放数据、政府地址查找服务、OpenStreetMap。

本仓库只放网页的发布版本，由开发仓库生成，请勿直接修改。
